# Hey, I'm Adam

I build and secure AI systems, from agentic workflows to the security layer around them. I founded [Fortulio](https://fortulio.com), a behavioural browser security company, and I'm doing an MSc in Artificial Intelligence at the University of Bristol.

My work sits between AI engineering, security engineering and forward deployed engineering: taking agentic systems from prototype to something a customer can trust in production.

## Current focus

- Agentic Security OS: a platform that takes AI-coded agentic apps from secure code to production-ready, evaluated agentic systems and workflows
- [Fortulio](https://fortulio.com): AI-powered behavioural detection in the browser, stopping risky employee actions such as credential theft, password reuse and unsafe AI tool use before they become breaches

## Projects

- [Tessera](https://github.com/V1Adait/Tessera): financial research workbench for credit and PE diligence. Answers are built from filings, every number carries a verified quote, and derived metrics are computed in code rather than by the model.
- [Context-MCP](https://github.com/V1Adait/Context-MCP): MCP server that gives coding agents structural codebase context through tree-sitter, with a hook that gates edits behind a validated task brief.
